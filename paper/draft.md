# Usable, Not True: What Network Internals Measure When Accuracy Is Blind

*Akanda Ashraf* — draft v0.1, 2026-07-31. Workshop-length target (6–8 pages).
Status markers: **[DONE]** result exists in `ExpOutput/`; **[PENDING]** pre-registered, not yet run.

## Abstract

Feature importance in deep networks is usually measured through predictions:
remove or permute a feature and observe the change in accuracy. We exhibit a
regime in which every such measure is provably blind. When a feature is
deterministically redundant given the others, the achievable risk is unchanged
by its removal, so risk-difference importance returns exactly zero — including
for a system's only true cause. We construct a benchmark realising this regime:
a chaotic driver and two nonlinear proxies, mutually redundant, where
conditional mutual information with the target is identically zero for all
three informative features and leave-one-out importance measures zero for each.
We then introduce a *deprivation probe*: paired-seed ablation contrasts on
permutation-invariant functionals of a deliberately capacity-constrained
network — activation geometry, weight spectra, compressibility, learning
curves — calibrated against injected noise features. The probe detects
accuracy-invisible features (participation-ratio shifts, |z| > 3), but its
ordering follows neither Shannon information, which is degenerate, nor causal
order, which it inverts: it tracks conditional V-information, the information
the network can cheaply extract. A pre-registered re-encoding of the target,
which changes which variable is cheap while leaving the data-generating process
and the redundancy structure untouched, reverses the ordering completely: the
dominant feature falls from eleven significant channels to one, and the true
cause rises from last place to second. Internal-representation importance
measures representational economics, not causal structure — a caution for
interpretability, and an instrument for usable information.

## 1. Introduction

The standard vocabulary of feature importance is predictive: leave-one-out
retraining (LOCO), permutation importance, and their relatives all define the
importance of a feature as some difference in achievable predictive
performance with and without it. This paper starts from a regime where that
entire vocabulary returns a provable zero.

If a feature is an exact function of the remaining features, removing it
changes nothing any predictor can achieve — the sigma-algebra generated by the
inputs is unchanged — so every risk-difference importance measure assigns it
exactly zero. This is not an edge case to be dismissed: deterministic and
near-deterministic redundancy is generic in physical, biological, and sensor
data, where many observables are functions of a shared latent state. In such a
system the *only true cause* of the target can receive an importance of
exactly zero (Section 3).

The question we ask: does the trained network itself still betray such
features? A network denied a feature must re-derive that feature's
contribution from its imprints on the remaining inputs, using its weights. If
that re-derivation costs representation, the cost should be visible *inside*
the network even when it is invisible in accuracy.

Contributions:

1. **A blindness theorem and its repair** (Sec. 2): risk-difference importance
   is identically zero under deterministic redundancy (Prop. 1); constraining
   the function class reopens the gap, and the reopened quantity is exactly
   conditional V-information (Prop. 2).
2. **A benchmark** (Sec. 3) in which the blindness is exact and the
   information structure is fully known: Shannon conditional information is
   zero for every informative feature, and ground-truth causal roles are
   known by construction.
3. **A deprivation probe** (Sec. 4): permutation-invariant functionals of a
   single small network, compared across paired-seed ablation arms and
   calibrated against injected noise features, resolving the incomparability
   of raw weights across retrainings.
4. **A three-way dissociation** (Sec. 5): the probe detects accuracy-blind
   features, and its detection ordering tracks usable (V-)information —
   dissociating from Shannon information (flat at zero) and from causal order
   (inverted: the true cause is the faintest signal).
5. **A pre-registered reversal experiment** (Sec. 6): re-encode the target so
   a different variable becomes the cheap one; the ordering must follow.
   **[PENDING]**

We explicitly do *not* claim a causal discovery method. The paper's point is
the opposite: internal-representation measurements are meters of
representational economics, and reading them causally is a category error.

## 2. Setup and theory

Let X = (X_1, …, X_d) be inputs, Y a target, ℓ a loss, and for S ⊆ [d] let
R\*(S) = inf_f E[ℓ(Y, f(X_S))] over all measurable f. Define population LOCO
importance Δ\*(j) = R\*([d] \ {j}) − R\*([d]) — the risk difference from
removing feature j.

**Proposition 1 (blindness).** *If X_j = g(X_{−j}) almost surely for some
measurable g, then σ(X) = σ(X_{−j}) up to null sets, hence
R\*([d] \ {j}) = R\*([d]) and Δ\*(j) = 0 — regardless of how strongly X_j
causes Y.*

The proof is three lines (the two infima range over the same set of random
variables) and the consequence is broad: LOCO, permutation importance,
Shapley-style value functions built on achievable risk, and Δ-AUC inherit the
zero. So does conditional mutual information: I(X_j; Y | X_{−j}) = 0.

**Proposition 2 (capacity reopens the gap).** *Let ℱ be a restricted class
(e.g., Lipschitz-bounded networks of fixed width) and
Δ_ℱ(j) = R_ℱ([d] \ {j}) − R_ℱ([d]) ≥ 0. There exist (g, h, ℱ) with
Δ_ℱ(j) > 0 while Δ\*(j) = 0: take Y = h(X_j), X_j = g(X_{−j}) with h ∘ g
requiring far more capacity than h.*

Δ_ℱ(j) is precisely the conditional predictive V-information
I_𝒱(X_j → Y | X_{−j}) of Xu et al. (2020): information is measured relative
to what a bounded observer can extract. Unlike Shannon information it is not
invariant to bijective recoding — computational cost counts.

**A predicted corollary, confirmed — but only once the statistic was measured
correctly.** Proposition 2 implies that the internal signatures should vanish
with capacity: widen the network until synthesising the missing feature is free
and there should be nothing left to measure. Sweeping widths 4–128 on
`redundancy_demo` (Sec. 6.3), the *z-scores* appear to refute this outright —
`proxy_cos` rises from Σ|z| = 34 to 148–201. Comparing raw paired deltas
instead reverses the conclusion. The raw effects decay exactly as predicted, by
roughly an order of magnitude, and the apparent growth is entirely a
normalisation artefact: wider networks train more reproducibly, so the null
spread in the denominator shrinks *faster* than the effect in the numerator.

This is a methodological trap worth stating separately, because it invalidates a
natural analysis and would be easy to publish by accident: **a z-score is only
comparable across sweep points if the calibration null's variance does not
itself depend on the swept parameter.** Here it does. Capacity changes both the
signal and the noise floor, and normalising by the latter conceals the behaviour
of the former.

**Remark (residual certificate).** When ℱ underfits the composite h ∘ g, the
residual Y − f̂(X_{−j}) is *dependent* on X_{−j} (a fitted conditional mean
has orthogonal residuals only if it is the conditional mean). Residual
dependence — not residual size — certifies that the class could not
synthesise the redundancy. We measure it with HSIC.

## 3. Benchmark: exact redundancy with known ground truth

`redundancy_demo` (code in `deepfeatselect/synthetic.py`): a chaotic logistic
map u_{t+1} = 3.9 u_t (1 − u_t) drives everything.

| column | definition | role |
|---|---|---|
| `driver` | u_t | the unique true cause of the target |
| `proxy_cos` | cos(2π u_t) | deterministic child of the driver |
| `proxy_sin` | sin(2π u_t) | deterministic child of the driver |
| `unrelated` | independent logistic map | irrelevant control |
| `null_k` | injected N(0,1) columns | calibration nulls |

Target: y = u_{t+1}, binarised at its median. Key structural facts, provable
from the definitions:

- (`proxy_cos`, `proxy_sin`) recovers u_t exactly (atan2), so `driver` is
  deterministically redundant. Conversely `driver` makes each proxy redundant.
- The logistic map is symmetric about u = ½ and so is cos(2πu); therefore
  **`proxy_cos` alone determines y**, and under the median split the label is
  a *single threshold* in proxy_cos: y > m ⟺ proxy_cos < c₀. In driver-space
  the same label is a two-sided interval.
- Hence I(X_j; Y | X_{−j}) = 0 for *all three* informative features — Shannon
  conditional information cannot rank them at all — while the causal roles
  are unambiguous: `driver` is the cause; the proxies are its effects.

**Measured blindness [DONE].** A random forest achieves R² = 1.00000 with all
columns; deleting any single informative column changes it by 0.00000.
A 3×128 network's LOCO Δ-AUC for `driver`: +0.0000, with penultimate-layer
CKA 1.000 between full and ablated models — the network's internals are
untouched at high capacity, exactly as Prop. 2 predicts. In a companion
cross-sectional SCM benchmark, LOCO scored *below chance* (AUROC 0.389) at
ranking true causes.

## 4. The deprivation probe

The obvious next move — compare the weights of networks trained with and
without the feature — is ill-posed: the loss is invariant under hidden-unit
permutation, and training is stochastic. Two equally good networks have
arbitrarily different weight tensors. Every functional we use is therefore
invariant to hidden-unit relabelling (most also to orthogonal rotations):

- **Activation geometry** (on 256 training rows and 256 Gaussian probes):
  active fraction, dead-unit fraction, distinct binary activation patterns
  (Hanin–Rolnick), mean per-unit firing entropy, participation ratio of the
  activation covariance (effective dimensionality).
- **Weight spectra**: normalised spectral entropy and stable rank per kernel;
  total Frobenius mass.
- **Compressibility**: Shannon entropy of the pooled 8-bit-quantised weight
  histogram (distribution only) and zlib bits-per-weight on a canonicalised
  ordering — hidden units sorted by incoming-kernel norm with the permutation
  propagated forward — which additionally sees inter-weight structure.
- **Learning dynamics**: final validation loss and area under the validation
  curve at a *fixed* epoch budget (early stopping would give each arm a
  different step budget and turn learning speed into a stopping-time
  artefact).
- **Residual structure**: HSIC(residual, inputs) with permutation p-values;
  residual autocorrelation on a contiguous test block.

**Protocol.** Small network (16 units × 2 layers — the constrained regime of
Prop. 2), no dropout or activation noise (they smear every functional with
their own randomness), fixed 80-epoch budget, contiguous 60/20/20 split of
n = 1500 rows. Arms: the full model and one ablation per feature
(columns zeroed, architecture unchanged). Arms are paired by seed; for each
functional F and arm a we form Δ_F(a, s) = F(a, s) − F(full, s) and score
candidates as z-scores against the pooled deltas of the null arms
(`unrelated`, `null_1`, `null_2`). Ten seeds; the null pool has 30 samples
per functional.

## 5. Results **[DONE — ExpOutput/internals10/]**

**P1 — accuracy blindness, confirmed.** Removing `driver` moved final
validation loss by +0.0001. Notably, removing any *null* feature consistently
*improved* the fit (mean Δ ≈ −0.005: less input noise). The driver's
signature at the loss level is thus not "removal hurts" but "removal fails to
pay the junk-removal dividend."

**P2 — internals see what accuracy cannot, with an important asymmetry.**
Aggregate z-scores against the null distribution (10 seeds):

| functional (selection) | driver | proxy_cos | proxy_sin |
|---|---|---|---|
| val-loss area (learning speed) | +2.19 | **+34.93** | +2.63 |
| final val-loss | +2.35 | **+14.72** | +1.55 |
| Frobenius mass | −0.80 | **+16.92** | −1.41 |
| participation ratio (data probes) | −0.73 | **+7.69** | −2.70 |
| participation ratio (random probes) | −1.90 | +4.55 | **−3.40** |
| active fraction (data probes) | +0.61 | **+5.89** | +1.27 |
| firing entropy (data probes) | −0.23 | **−5.06** | −0.28 |
| stable rank | −1.68 | **+3.97** | −2.31 |
| distinct activation patterns | +2.36 | +3.70 | +1.59 |
| residual HSIC | −2.06 | −0.04 | −1.74 |

Reading:

- **`proxy_cos` dominates every channel** (z up to +35). Deprived of it, the
  network trains ~2× slower, ends at higher loss, recruits more units, holds
  more weight mass, and its weights become less compressible (quantised
  entropy +2.3σ, gzip +2.6σ in the 3-seed run). Mechanism: under the median
  split the task is *linearly separable in proxy_cos alone*; the network
  leans on the cheapest coordinate, and the probes report the cost of taking
  it away.
- **`proxy_sin` is the clean accuracy-blind detection.** Its removal leaves
  the loss statistically unchanged (z = +1.55, n.s.) yet its representational
  fingerprint — participation ratio, z = −3.40 (random probes), −2.70 (data
  probes) — replicated across both the 3-seed and 10-seed runs.
- **`driver` — the true cause — sits at the detection floor**: four channels
  at |z| ≈ 2.0–2.4 out of 57 tests (≈3 expected by chance); one channel that
  looked strong at 3 seeds (Frobenius, −3.19) collapsed at 10 seeds (−0.80).
  Honest summary: a feature that is redundant *and substituted-away-from*
  leaves a faint trace at best.

**The dissociation.** Shannon conditional information orders the three
features (0, 0, 0) — no ranking. Causal structure orders them
driver ≻ {proxies}. The measured ordering is
**proxy_cos ≫ proxy_sin ≫ driver ≈ floor** — the usable-information
ordering: exactly how cheaply each feature's contribution can be extracted by
this class under this encoding. Network internals meter V-information.

**User-facing corollary.** Two hypotheses from the design phase resolved as:
(a) the *deprived* network gets denser and heavier (active fraction +0.06,
Frobenius +1.23), i.e., density signals compensation work, and (b) its
weights carry *higher* entropy — consistent with a weight-decay regime where
unused pathways decay and hard-working ones grow varied weights. Both signs
attach to deprivation, not to "better learning" in general.

## 6. The reversal experiment **[DONE — predictions were registered in Sec. 6 of draft v0.1 before the run]**

### 6.1 Result

Re-encoding the target moved the ordering, as predicted, and by a wide margin.
Aggregating |z| over all 22 functionals:

| feature | baseline Σ\|z\| | reversal Σ\|z\| | baseline max \|z\| | reversal max \|z\| | channels \|z\|>2 |
|---|---|---|---|---|---|
| `proxy_cos` | **105.2** | 17.9 | 39.8 | 4.5 | 11 → **1** |
| `proxy_sin` | 27.8 | **52.3** | 4.5 | 9.6 | 5 → **11** |
| `driver` | 19.5 | 36.9 | 2.8 | 8.8 | 2 → **5** |

Rank by total |z|: **`proxy_cos` > `proxy_sin` > `driver`** becomes
**`proxy_sin` > `driver` > `proxy_cos`**.  The previously dominant feature is
now last, and both previously faint features are ahead of it.  The data
generating process was untouched; only the label encoding changed.

Channel by channel, the swap is not an artefact of one statistic:

| functional | `proxy_cos` | `proxy_sin` | `driver` |
|---|---|---|---|
| val-loss area | +39.8 → **+1.1** | +1.4 → **+9.6** | +0.7 → +3.1 |
| Frobenius mass | +12.5 → **−0.2** | −0.8 → **+6.6** | −0.4 → +0.9 |
| participation ratio (data) | +6.3 → **−0.7** | −3.6 → +2.4 | −1.0 → **+4.0** |
| active fraction (data) | +4.6 → **+0.7** | +1.6 → +3.3 | +1.1 → +2.6 |

Predictions 1 and 2 hold: `proxy_cos` collapses to the null floor (an order of
magnitude on every channel that carried it), and `driver` and `proxy_sin` rise
to the top.  Prediction 3 holds for `driver`, whose final-validation-loss delta
stays insignificant (+0.69) while its internal signature reaches |z| = 8.8 —
another accuracy-blind detection, and this time of the true cause.  It fails for
`proxy_sin`, which becomes visible in the loss as well (+4.4): with `proxy_cos`
demoted to irrelevance the label has only two routes left, and the network's
preference between them is strong enough to register at the loss level.

**Interpretation.**  The ordering follows the encoding, not the variables and
not the causal structure.  `driver` is the unique cause under both labels and
its position moves from last to second; `proxy_cos` is a non-causal descendant
under both and moves from first to last.  What the probe tracks is which
coordinate the class can most cheaply separate, which is conditional
V-information, and the manipulation confirms it by construction rather than by
correlation.

### 6.2 The Grad-CAM channel: a negative result

Three attribution-structure statistics were added before the run — relevance
concentration (Gini over units), class separation (cosine distance between
class-conditional relevance maps), and within-class map consistency against a
label-shuffled baseline — computed on the penultimate-layer Grad-CAM map
``ReLU(w_k h_k)``, which is exact in closed form because the head is affine.

They detected nothing.  All three sit below |z| = 1.6 for every feature in both
arms, while the geometry and learning-curve channels moved by factors of ten.
Two candidate explanations, untested: at 16 units the relevance vector may be
too low-dimensional for these summaries to resolve, and on a task the network
solves almost perfectly the class-conditional maps may saturate.  We report the
channel as measured and unhelpful in this regime rather than dropping it.

### 6.3 Capacity sweep: a refuted prediction **[DONE]**

Widths 4, 8, 16, 32, 64, 128, four seeds each, otherwise the baseline protocol.
Σ|z| over all functionals:

| width | `driver` | `proxy_cos` | `proxy_sin` |
|---|---|---|---|
| 4 | 22.4 | 34.4 | 21.3 |
| 8 | 30.2 | 105.8 | 27.0 |
| 16 | 23.8 | 106.1 | 32.2 |
| 32 | 25.7 | 127.7 | 48.7 |
| 64 | 19.7 | **200.8** | 41.1 |
| 128 | 19.3 | 147.9 | 32.1 |

On this reading nothing decays and the Sec. 2 prediction looks refuted, with the
dominant feature's signature growing 4–6x.  It is not.  Repeating the sweep while
recording the numerator and denominator of every z separately gives the opposite
answer:

| width | raw Δ participation ratio (`proxy_cos`) | null spread | raw Δ val-loss area (`proxy_cos`) | null spread |
|---|---|---|---|---|
| 4 | +0.0515 | 0.00555 | +0.1771 | 0.02341 |
| 16 | +0.0209 | 0.00449 | +0.0846 | 0.00204 |
| 64 | +0.0084 | 0.00077 | +0.0506 | 0.00235 |
| 128 | **+0.0052** | **0.00062** | **+0.0474** | **0.00274** |

The raw effects **decay as Proposition 2 predicts** — participation ratio by 9.9x
and val-loss area by 3.7x from width 4 to 128.  The null spread decays too, and
faster: 9.0x and 8.5x respectively.  Dividing one by the other leaves a ratio that
is flat or rising, which is what the z table shows and what misled us.

The lesson generalises beyond this experiment.  **A z-score is comparable across
sweep points only if the calibration null's variance is independent of the swept
parameter.** Capacity violates that: it changes the signal and the noise floor
together.  Any null-calibrated statistic swept over a parameter that also
controls training stability is exposed to the same inversion, and reporting only
the normalised quantity would have turned a confirmation into a refutation.

Proposition 2 therefore stands, including its scoping consequence: the probe is
informative in the capacity-constrained regime and its raw sensitivity falls away
as width grows.

### 6.4 Design

The dissociation claim says the ordering tracks the (class, encoding) pair,
not the variables. It therefore makes a falsifiable prediction under a
designed manipulation of the *encoding alone*.

**Design.** Same system, same probe, same architecture; only the label
changes: label = **1[u_t > ½]** (threshold on the driver) instead of the
median split of u_{t+1}. Structural consequences, provable from the
definitions: cos(2π(1−u)) = cos(2πu), so `proxy_cos` is *exactly
uninformative* about this label (its conditional is 50/50 alone);
sin(2πu) > 0 ⟺ u < ½, so `proxy_sin` carries the label as a sign bit;
`driver` carries it as a single threshold. Deterministic redundancy is
preserved (drop `driver` → sign of `proxy_sin` suffices; drop `proxy_sin` →
`driver` suffices), so Shannon conditional information remains degenerate at
zero for both — the dissociation stays testable.

**Predictions (committed before running).**
1. `proxy_cos`'s deprivation signature collapses to the null floor (it
   becomes irrelevant-given-others *and* marginally uninformative): its
   previously dominant channels drop by an order of magnitude, |z| < 2 or
   near it.
2. `driver` and `proxy_sin` rise to the top of the ordering.
3. Loss-level blindness persists for `driver` and `proxy_sin` (each remains
   substitutable).

**Decision rule.** H survives if the rank ordering of aggregate |z| follows
the new cheapness ordering (driver, proxy_sin ≫ proxy_cos). H is refuted if
the ordering is unchanged (probes measure something sticky about the
variables) or follows causal order independent of encoding (probes measure
causality after all — a more interesting refutation).

**Additional hardening [PENDING]:** (i) capacity sweep — all signatures must
decay toward null as width grows (Prop. 2); persistence at 128+ units
refutes the proposed mechanism; (ii) rank-correlation of internal z-scores
against directly estimated Δ_ℱ across a battery of synthetic systems;
(iii) a second and third system family — one system is an anecdote.

## 7. Application: auditing identifiability before ranking **[DONE]**

Proposition 1 is only useful if its condition can be checked on data, which it
can: regress each feature on the rest and read off what is left.  A feature with
high leave-one-out reconstruction has an importance that is not small but
*undefined up to the choice of representative*, and a ranking that does not say
so is how an irreproducible biomarker gets published.

**Real data, no ground truth required.**  On Breast Cancer Wisconsin (569 fine
needle aspirates, 30 features), the six most reconstructible columns in the
entire table are exactly the geometric family — `mean_radius` (R² = 0.990),
`worst_radius` (0.988), `mean_perimeter` (0.986), `worst_perimeter` (0.977),
`mean_area` (0.975), `worst_area` (0.967) — recovered without the audit being
told that perimeter ≈ 2πr and area ≈ πr².  Their leave-one-out accuracy drops
span +0.006 to +0.023 on a 171-patient test split, i.e. **one to four patients**:
the entire importance column for these six diagnostic features is at
quantisation noise.  On Cleveland heart disease (297 patients, nine numeric
clinical variables, chosen by design to be distinct measurements) the audit
returns **0/9** with a maximum R² of 0.30.  The instrument separates the two
regimes unsupervised, which is what makes it usable where the structure is
unknown.

**Simulated trial with ground truth.**  To show the downstream consequence we
simulate a randomised trial (n = 4000, 1:1 allocation) in which a latent pathway
modifies the treatment effect and four assays read that pathway.  Randomisation
identifies the average effect directly (true +0.300, estimated +0.270,
95% CI [0.216, 0.334]); nothing in this paper improves on that, and the point of
reporting it is to mark the boundary.  The open question is which assay a
companion diagnostic should use.  All four readouts carry leave-one-out
importance between −0.00018 and +0.00019 — indistinguishable from injected
random noise columns — while the audit flags all four at R² 0.989–0.998.  Their
effect-modification signals agree to three decimals (+1.2532, +1.2532, +1.2515),
and across eight independent replications **three different assays take first
place** (4/8, 3/8, 1/8).  A diagnostic built on the winner of any single trial
names a different assay depending on which trial ran.

Two further observations from the same run.  The most predictive column in the
study is a post-randomisation symptom score (LOCO +0.521, ~2700× any valid
marker), which is a descendant of the outcome and invalid as a biomarker — the
Markov-blanket ceiling of Section 1 in clinical dress.  And one redundant
readout, a squared measurement, has an effect-modification gap of −0.0025:
**informational redundancy does not imply interchangeability under a decision
rule**, because a median split on a magnitude cannot separate strata defined by
a sign.  An audit intended to support deployment must therefore check
monotonicity against the rule, not information content alone.

The operational output is a shortlist rather than a winner: redundant groups
collapse to one testable hypothesis each (7 candidate columns → 4 hypotheses in
the simulation), which is where experimental budget is saved, and within a group
the choice becomes a cost decision the data is indifferent to (40 versus 1200
per assay here, at equal predictive content).

**The constructive repair.**  Proposition 1 says where single-feature ablation
is undefined; the complementary question is where it becomes defined again.
Searching for the smallest set whose *joint* removal destroys the signal answers
it, and the search must be over subsets rather than greedy — greedy fails in
precisely the regime the procedure targets, because every single removal scores
about zero, so the first step selects on noise and commits to a wrong branch
(on the benchmark it returned a three-element set containing a provably
irrelevant column, and still had not broken the target).

Scored against the generator, the subset search recovers `{driver, proxy_cos}`,
matching the independently recorded minimal sufficient sets; a valid removal set
must intersect every sufficient set or a route survives, which is checkable and
is a test.  The repair is stark on that benchmark: single-feature LOCO within
the set maxes at +0.0000 while group LOCO on the set is +0.6222, a ratio of
about 1.5e4.  Across datasets the set size behaves as a count of independent
predictive routes: 2 for the benchmark, 1 for Cleveland (`ca`, +0.089), and
**none up to size 3 for Breast Cancer Wisconsin** (best three-subset +0.029),
i.e. at least four routes to the diagnosis in a dataset in wide use as a feature
selection benchmark.  The same search on `nonlinear_scm` returns `{x_effect}`,
the target's child — the shortest *predictive* route again running through an
effect, which is the Markov-blanket ceiling reappearing at the set level.

## 8. Related work

**Usable information.** Xu et al. (2020) define 𝒱-information;
Ethayarajh et al. (2022) apply it to dataset difficulty. We use *deprivation
signatures inside the network* as the measurement instrument, and exhibit a
regime where Shannon is exactly degenerate so the dissociation is clean.

**Probing.** MDL probes (Voita & Titov, 2020) and control tasks
(Hewitt & Liang, 2019) measure extractability of properties *from
representations of inputs*. Our probe measures the representational cost of
*feature removal* in the predictor itself, with an explicit null calibration
and an explicit capacity-regime condition.

**Importance under dependence.** Strobl et al. (2008), Hooker, Mentch & Zhou
(2021) document failures of permutation/impurity importance under correlated
features; Covert et al. (2020, SAGE) address redundancy via Shapley averaging.

An earlier draft of this paper claimed Shapley methods inherit the
Proposition 1 zero. **That claim is false, and the measurement is more
interesting than the claim was.** Proposition 1 concerns the single coalition
``S = N \ {j}``; a Shapley value averages that term with every other coalition,
and for a feature that alone determines the target the ``S = empty`` term is as
large as the signal. Measured on `redundancy_demo` with an exact enumeration
over all coalitions and a retrained value function:

| feature | SAGE | LOCO | role |
|---|---|---|---|
| `driver` | **+0.4513** | +0.0000 | true cause |
| `proxy_cos` | **+0.4512** | −0.0000 | proxy, individually sufficient |
| `proxy_sin` | +0.1336 | +0.0000 | proxy, not individually sufficient |
| `unrelated` | −0.0426 | +0.0000 | irrelevant |

SAGE recovers what leave-one-out cannot: three informative features at +0.45,
+0.45 and +0.13 where every risk difference is zero to four decimals. Prop. 1
therefore bounds risk-difference importance specifically, not attribution in
general, and the paper's scope is corrected accordingly.

**But solving blindness is not solving orientation, and here the failure is
structural rather than empirical.** `driver` and `proxy_cos` are separated by
0.0001. They are interchangeable in *every* coalition — each alone determines
the target, and each makes the other redundant — so they are symmetric players
in the coalitional game, and the Shapley **symmetry axiom** *requires* that they
receive identical credit. The property that makes Shapley a principled fair
division is exactly what forbids it from distinguishing a cause from an
informationally equivalent effect. No amount of data changes this; it follows
from the axiom.

This is known, and we claim only the measurement. Asymmetric Shapley Values
(Frye, Rowat & Feige, 2020) were introduced precisely to relax symmetry for this
reason, observing that for two bijectively related features — one a
deterministic causal ancestor of the other — symmetry splits credit evenly where
the ancestor should receive it all; and Ma & Tourani (2020) show a variable that
is neither cause nor effect can outscore every true cause. Our contribution here
is the exact numerical demonstration on a system where the tie is forced to four
decimal places, not the observation that it occurs. ASV is also the natural
remedy for a practitioner who has a partial causal order to supply.

On `nonlinear_scm` the same ceiling appears in the form seen throughout this
paper: SAGE ranks `x_effect`, a *child* of the target, **first of nine** at
+0.7103 — an order of magnitude above the true direct causes (`x_cause1`
+0.0853, `x_cause2` +0.0769, `z` +0.0460). SAGE is a better instrument than
LOCO and ranks the causes above the confounded and irrelevant columns
correctly, but its top answer is still an effect.

One practical caveat measured alongside: the retrained value function is a
cross-validated forest, so `v(S)` is estimated rather than exact and injected
null columns receive |SAGE| up to ≈0.05. `shapley_noise_floor` reports this
resolution limit, below which a Shapley value carries no information whatever
axioms it satisfies.

**Representation geometry and ablation.** Participation ratio as effective
dimensionality (Gao et al.); activation-region counting (Hanin & Rolnick, 2019);
intrinsic dimension (Ansuini et al., 2019); heavy-tailed weight spectra
(Martin & Mahoney); description length of models (Blier & Ollivier, 2018).
Meyes et al. (2019, 2020) ablate *neurons* and report that a unit's importance
tracks how much its incoming weight distribution moved during training, which is
the closest antecedent to our weight-side channels — but the ablated object
there is a neuron and the question is which units matter, where ours is a
feature and the question is what the network does to compensate for losing it.
We repurpose these statistics as *paired contrasts* against a null-calibrated
baseline rather than as absolute diagnostics.

**Group and subset ablation.** Grouped feature ablation is standard practice and
available in mainstream tooling (e.g. Captum's feature masks), and sufficient
input subsets (Carter et al., 2019) search for minimal subsets that preserve a
decision. The construction here is the complement — the minimal subset whose
*removal* destroys the signal — and its motivation is specific: it is the
coarsest grouping at which Proposition 1 stops applying, so it identifies where
ablation importance regains a meaning rather than merely grouping features that
a practitioner already knows are related.

**Feature selection with gates.** LassoNet (Lemhadri et al., 2021),
stochastic gates (Yamada et al., 2020). Companion experiments (repo) show
gate-based importances inherit the same Markov-blanket ceiling as every
predictive method — consistent with, and motivating, the present framing.

## 9. Limitations

One synthetic family so far; small-capacity regime only (and necessarily so —
Prop. 2 makes the large-capacity version provably empty); ten seeds with a
30-sample null; 57 hypothesis tests, so individual |z| ≈ 2 findings (the
driver row) are at the floor and we treat them as such; the probe orders
features but does not orient causes — orientation requires assumptions
external to prediction (noise asymmetry, non-invertibility, intervention),
which we treat in companion work; and the novelty of the assembly is asserted
"to our knowledge" pending a systematic literature pass.

## 10. Conclusion

Risk-difference importance has an exact blind spot, and inside it the trained
network still talks — but about economics, not causality. What its internals
reveal is which features the class can cheaply use, an estimate of
conditional V-information that survives when Shannon information is
degenerate and inverts the causal ordering. The practical reading for
interpretability: an internal-representation importance is a statement about
the model's budget, and re-encode the data and the ordering will follow the
budget, not the mechanism. That sentence is a prediction until Section 6
runs; it is written down here first, on purpose.
