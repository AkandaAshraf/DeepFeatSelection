\begin{abstract}
Feature importance in deep networks is usually measured through predictions:
remove or permute a feature and observe the change in accuracy. We exhibit a
regime in which every such measure is provably blind. When a feature is
deterministically redundant given the others, the achievable risk is unchanged
by its removal, so risk-difference importance returns exactly zero---including
for a system's only true cause. We construct a benchmark realising this regime,
in which conditional mutual information with the target is identically zero for
all informative features and leave-one-out importance measures zero for each.
We then introduce a \emph{deprivation probe}: paired-seed ablation contrasts on
permutation-invariant functionals of a capacity-constrained network---activation
geometry, weight spectra, compressibility, learning curves---calibrated against
injected noise features. The probe detects accuracy-invisible features, but its
ordering follows neither Shannon information, which is degenerate here, nor
causal order, which it inverts: it tracks usable ($\Vinf$-)information, what the
model class can cheaply extract. A pre-registered re-encoding of the target,
which changes which variable is cheap while leaving the data-generating process
and the redundancy structure untouched, reverses the ordering completely.
Internal-representation importance measures representational economics, not
causal structure---a caution for interpretability, and an instrument for usable
information. We bound the blindness result carefully: it binds
removal-and-permutation estimators, while impurity, Shapley and mutual
information all recover the true cause on the same benchmark, so internal
measurement is not the practical remedy and we do not claim it is. We also
report a target-specification failure that survived four experimental sweeps
undetected, and the cheap guard against it.
\end{abstract}

\section{Introduction}

The standard vocabulary of feature importance is predictive: leave-one-out
retraining (LOCO), permutation importance, and their relatives all define the
importance of a feature as a difference in achievable predictive performance
with and without it. This paper starts from a regime where that entire
vocabulary returns a provable zero.

If a feature is an exact function of the remaining features, removing it changes
nothing any predictor can achieve---the $\sigma$-algebra generated by the inputs
is unchanged---so every risk-difference importance measure assigns it exactly
zero. This is not an edge case. Deterministic and near-deterministic redundancy
is generic in physical, biological and sensor data, wherever many observables
are functions of a shared latent state. In such a system the \emph{only true
cause} of the target can receive an importance of exactly zero.

The question we ask is whether the trained network still betrays such features.
A network denied a feature must re-derive that feature's contribution from its
imprints on the remaining inputs. If that re-derivation costs representation,
the cost should be visible \emph{inside} the network even when it is invisible
in accuracy.

We should say at once what this does \emph{not} motivate. The blindness binds
removal-and-permutation estimators, not feature importance in general: on the
same benchmark, mutual information assigns the true cause $0.692$ in
milliseconds (Sec.~\ref{sec:scope}). So internal measurement is not the
practical remedy here, and we do not argue that it is. The interest is in what
the internal signal turns out to \emph{be}: it detects features that removal
cannot see, orders them by neither Shannon information nor causal role, and
moves when the target is re-encoded while the data-generating process is held
fixed.

\paragraph{Contributions.}
\begin{enumerate}\itemsep2pt
\item A blindness result, its \emph{scope}, and its repair
  (Sec.~\ref{sec:theory}): risk-difference importance is identically zero under
  deterministic redundancy (Prop.~\ref{prop:blind}); we establish empirically
  that this binds leave-one-out and permutation but \emph{not} impurity,
  Shapley or mutual information (Sec.~\ref{sec:scope}); and constraining the
  function class reopens the gap (Prop.~\ref{prop:capacity}), the reopened
  quantity being $\Vinf$-information \citep{xu2020theory}.
\item A benchmark (Sec.~\ref{sec:benchmark}) in which the blindness is exact,
  Shannon conditional information is zero for every informative feature, and
  ground-truth causal roles are known by construction.
\item A deprivation probe (Sec.~\ref{sec:probe}): permutation-invariant
  functionals of a single small network, compared across paired-seed ablation
  arms and calibrated against injected noise, resolving the incomparability of
  raw weights across retrainings.
\item A three-way dissociation (Sec.~\ref{sec:results}): the probe detects
  accuracy-blind features, and its ordering tracks usable information---%
  dissociating from Shannon information, which is flat at zero, and from causal
  order, which it inverts.
\item A pre-registered reversal experiment (Sec.~\ref{sec:reversal}) confirming
  the attribution by manipulation rather than correlation.
\item A target-specification failure reported in full (Sec.~\ref{sec:detect}):
  scoring a detection method against a target the fitted model never learned
  measures the target's learnability, not the method---silently, with a
  well-formed AUROC.
\end{enumerate}

We explicitly do \emph{not} claim a causal discovery method. The paper's point
is the opposite: internal-representation measurements are meters of
representational economics, and reading them causally is a category error.

\section{Setup and theory}\label{sec:theory}

Let $X = (X_1,\dots,X_d)$ be inputs, $Y$ a target, $\ell$ a loss, and for
$S \subseteq [d]$ let $\Risk^*(S) = \inf_f \mathbb{E}[\ell(Y, f(X_S))]$ over all
measurable $f$. Define the population LOCO importance
$\Delta^*(j) = \Risk^*([d]\setminus\{j\}) - \Risk^*([d])$.

\begin{proposition}[Blindness]\label{prop:blind}
If $X_j = g(X_{-j})$ almost surely for some measurable $g$, then
$\sigma(X) = \sigma(X_{-j})$ up to null sets, hence
$\Risk^*([d]\setminus\{j\}) = \Risk^*([d])$ and $\Delta^*(j) = 0$---regardless
of how strongly $X_j$ causes $Y$.
\end{proposition}

The proof is immediate: the two infima range over the same set of random
variables. Every measure defined as a difference of achievable risks inherits
the zero, as does conditional mutual information, $I(X_j;Y \mid X_{-j}) = 0$.

\subsection{How far the zero reaches}\label{sec:scope}

Proposition~\ref{prop:blind} is a statement about risk \emph{differences}, and
it is worth establishing empirically which estimators that actually covers,
because the natural reading---that feature importance fails in this
regime---is too broad.

Table~\ref{tab:scope} settles it. Leave-one-out and permutation importance are
both exactly zero for the true cause---permutation is a risk difference too, so
it inherits as the theory requires. Impurity importance, Shapley values and
mutual information all recover it. Impurity does not difference two risks but
accumulates loss reduction over splits, so when several features carry the same
information trees choose among them and credit is \emph{distributed} rather than
cancelled; mutual information is marginal rather than conditional and the
argument does not touch it; Shapley averages over all coalitions, and the
$S = \emptyset$ term is as large as the signal.

We state the consequence plainly because it bounds this paper's motivation.
Mutual information assigns the system's only true cause $0.692$, in
milliseconds, on a benchmark constructed to defeat feature importance. The
blindness is therefore real, exact, and \emph{narrow}: it binds
removal-and-permutation estimators specifically, and the cheapest remedy is a
different estimator rather than instrumentation of the network. What the
following sections establish is not that internal measurement is \emph{needed}
here, but what it \emph{measures} when applied---which turns out not to be what
one would assume.

\begin{proposition}[Capacity reopens the gap]\label{prop:capacity}
Let $\Fclass$ be a restricted class and
$\Delta_\Fclass(j) = \Risk_\Fclass([d]\setminus\{j\}) - \Risk_\Fclass([d]) \ge 0$.
There exist $(g,h,\Fclass)$ with $\Delta_\Fclass(j) > 0$ while
$\Delta^*(j) = 0$: take $Y = h(X_j)$ and $X_j = g(X_{-j})$ with $h \circ g$
requiring far more capacity than $h$.
\end{proposition}

$\Delta_\Fclass(j)$ is the \emph{conditional} predictive $\Vinf$-information
$I_\Vinf(X_j \to Y \mid X_{-j})$ of \citet{xu2020theory}: information relative
to what a bounded observer can extract, and unlike Shannon information not
invariant to bijective recoding---computational cost counts.

A caution carried through the paper: this conditional quantity is the natural
theoretical object, but it is \emph{not} what the probe reports. Under
redundancy it is near zero for every informative feature---that is
Prop.~\ref{prop:blind}---so it cannot supply an ordering. Which variant the
probe's ordering follows is measured in Appendix~\ref{app:variant} and only
partly resolved.

\begin{remark}[Residual certificate]
When $\Fclass$ underfits the composite $h \circ g$, the residual
$Y - \hat f(X_{-j})$ is \emph{dependent} on $X_{-j}$, since a fitted conditional
mean has orthogonal residuals only if it is the conditional mean. Residual
dependence---not residual size---certifies that the class could not synthesise
the redundancy. We measure it with HSIC.
\end{remark}

\section{Benchmark}\label{sec:benchmark}

A chaotic logistic map $u_{t+1} = 3.9\,u_t(1-u_t)$ drives everything. The target
is $y = u_{t+1}$, binarised at its median. Observed columns are
$\texttt{driver} = u_t$, $\texttt{proxy\_cos} = \cos(2\pi u_t)$,
$\texttt{proxy\_sin} = \sin(2\pi u_t)$, and an independent chaotic map as an
irrelevant control.

Three structural facts follow from the definitions. The pair
$(\texttt{proxy\_cos}, \texttt{proxy\_sin})$ recovers $u_t$ exactly via
$\mathrm{atan2}$, so \texttt{driver} is deterministically redundant; conversely
\texttt{driver} makes each proxy redundant. The logistic map is symmetric about
$u = \tfrac12$ and so is $\cos(2\pi u)$, so \texttt{proxy\_cos} alone determines
$y$, and under the median split the label is a \emph{single threshold} in that
coordinate while being a two-sided interval in driver space. Consequently
$I(X_j;Y\mid X_{-j}) = 0$ for all three informative features: Shannon
conditional information cannot rank them at all, while the causal roles are
unambiguous.

\paragraph{Measured blindness.} A random forest achieves $R^2 = 1.00000$ with
all columns; deleting any single informative column changes it by $0.00000$. A
$3\times128$ network's LOCO $\Delta$-AUC for \texttt{driver} is $+0.0000$, with
penultimate-layer CKA of $1.000$ between full and ablated models. In a companion
cross-sectional SCM benchmark, LOCO scores \emph{below chance} (AUROC $0.389$)
at ranking true causes, because the target's child is the most predictive column
present.

\section{The deprivation probe}\label{sec:probe}

Comparing the weights of networks trained with and without a feature is
ill-posed: the loss is invariant under hidden-unit permutation and training is
stochastic, so two equally good networks have arbitrarily different tensors.
Every functional we use is therefore invariant to hidden-unit relabelling, and
most also to orthogonal rotation.

\begin{itemize}\itemsep2pt
\item \textbf{Activation geometry:} active fraction, dead-unit fraction,
  distinct binary activation patterns \citep{hanin2019complexity}, per-unit
  firing entropy, and the participation ratio of the activation covariance.
\item \textbf{Weight spectra:} normalised spectral entropy and stable rank per
  kernel; total Frobenius mass.
\item \textbf{Compressibility:} entropy of the pooled 8-bit-quantised weight
  histogram, and zlib bits-per-weight on a \emph{canonicalised} ordering---%
  hidden units sorted by incoming-kernel norm with the permutation propagated
  forward---which additionally sees inter-weight structure.
\item \textbf{Learning dynamics:} final validation loss and area under the
  validation curve at a \emph{fixed} epoch budget. Early stopping would give
  each arm a different step budget and turn learning speed into a stopping-time
  artefact.
\item \textbf{Residual structure:} HSIC between residuals and inputs with
  permutation $p$-values.
\end{itemize}

\paragraph{Protocol.} A small network (16 units, 2 layers---the constrained
regime of Prop.~\ref{prop:capacity}), no dropout or activation noise, a fixed
80-epoch budget, and a contiguous $60/20/20$ split of $n=1500$ rows. Arms are
the full model and one ablation per feature, with columns zeroed rather than
dropped so the architecture is unchanged. Arms are paired by seed; for each
functional $F$ and arm $a$ we form $\Delta_F(a,s) = F(a,s) - F(\text{full},s)$
and score candidates as $z$-scores against the pooled deltas of injected
noise arms.

\section{Results: a three-way dissociation}\label{sec:results}

Ten seeds. Removing \texttt{driver}---the true cause---moves final validation
loss by $+0.0001$. Removing any \emph{null} feature consistently \emph{improves}
the fit (mean $\Delta \approx -0.005$, less input noise), so the driver's
loss-level signature is not ``removal hurts'' but ``removal fails to pay the
junk-removal dividend''.

Table~\ref{tab:dissociation} shows the dissociation.
\texttt{proxy\_cos} dominates every channel; under the median split the task is
\emph{linearly separable in that coordinate alone}, and the network leans on the
cheapest available representation. \texttt{proxy\_sin} is the clean
accuracy-blind detection: its removal leaves the loss statistically unchanged
($z = +1.55$) yet its participation-ratio fingerprint reaches $z = -3.40$,
replicated across independent runs. \texttt{driver}---the true cause---sits at
the detection floor, with four channels at $|z| \approx 2.0$--$2.4$ out of 57
tests, where roughly three are expected by chance; one channel that looked
strong at three seeds did not replicate at ten.

So Shannon conditional information orders the three features $(0,0,0)$; causal
structure orders them $\texttt{driver} \succ \{\text{proxies}\}$; the measured
ordering is $\texttt{proxy\_cos} \gg \texttt{proxy\_sin} \gg \texttt{driver}$.
The probe meters usable information.

\section{The reversal experiment}\label{sec:reversal}

The dissociation claim says the ordering tracks the (class, encoding) pair, not
the variables, so it makes a falsifiable prediction under a manipulation of the
\emph{encoding alone}. Predictions were registered in the repository before the
run.

\paragraph{Design.} Same system, same probe, same architecture; only the label
changes, to $\mathbb{1}[u_t > \tfrac12]$. Since
$\cos(2\pi(1-u)) = \cos(2\pi u)$, \texttt{proxy\_cos} becomes \emph{exactly}
uninformative; since $\sin(2\pi u) > 0 \iff u < \tfrac12$, \texttt{proxy\_sin}
carries the label as a sign bit and \texttt{driver} as a single threshold.
Deterministic redundancy is preserved, so Shannon conditional information
remains degenerate and the dissociation stays testable.

The ordering reverses completely (Table~\ref{tab:reversal}), and not through one
statistic: val-loss area moves $+39.8 \to +1.1$ for \texttt{proxy\_cos} and
$+1.4 \to +9.6$ for \texttt{proxy\_sin}; Frobenius mass $+12.5 \to -0.2$ and
$-0.8 \to +6.6$. Under the new encoding, \texttt{driver} is detected at
$|z| = 8.8$ while its validation-loss delta stays insignificant at $+0.69$---an
accuracy-blind detection of the true cause, obtained because the encoding made
it cheap rather than because it is causal. \texttt{driver} is the unique cause
under \emph{both} labels and its position moves from last to second.

One registered prediction failed: \texttt{proxy\_sin} also becomes visible in
the loss ($+4.4$). With \texttt{proxy\_cos} demoted to irrelevance the label has
only two routes left, and the network's preference between them registers at the
loss level.

\paragraph{A reported null.} Three Grad-CAM-style attribution statistics
\citep{selvaraju2017gradcam}---relevance concentration, class separation, and
within-class map consistency against a label-shuffled baseline, computed on the
closed-form penultimate map $\mathrm{ReLU}(w_k h_k)$---detected nothing, sitting
below $|z| = 1.6$ for every feature in both arms while geometry channels moved
by factors of ten.

\section{Auditing identifiability before ranking}\label{sec:audit}

Prop.~\ref{prop:blind} is actionable only if its condition can be checked, which
it can: regress each feature on the rest and read off what remains. A feature
with high leave-one-out reconstruction has an importance that is not small but
\emph{undefined up to the choice of representative}.

On Breast Cancer Wisconsin (569 aspirates, 30 features), the six most
reconstructible columns are exactly the geometric family---%
\texttt{mean\_radius} ($R^2 = 0.990$) through \texttt{worst\_area}
($0.967$)---recovered without the audit being told that perimeter $\approx 2\pi
r$. Their leave-one-out accuracy drops span $+0.006$ to $+0.023$ on a
171-patient test split: one to four patients. On Cleveland heart disease
(297 patients, nine numeric clinical variables) the audit returns $0/9$ with a
maximum $R^2$ of $0.30$. The instrument separates the two regimes unsupervised.

\paragraph{Derivation, not correlation.} Across five datasets ordered by how the
columns arose, the split is clean: simulated-exact ($R^2_{\max} = 1.000$),
derived by formula (Wisconsin, $0.990$) and derived by training (ClinVar
predictor ensembles, $0.980$) reach the non-identifiable band, while separately
measured columns do not---DepMap CRISPR gene-effect profiles reach only $0.329$
and Cleveland $0.300$, with nothing in between. The boundary runs \emph{through}
biology rather than around it: protein-complex subunits are as biologically
coupled as variables get and remain identifiable, because each is measured
independently and measurement error cannot be predicted away. Deterministic
redundancy tracks \emph{derivation}.

\paragraph{Consequence.} On ClinVar variant-effect predictors, 23 columns occupy
$2.7$ effective dimensions. Since ACMG/AMP criteria PP3 and BP4 count
computational evidence toward a pathogenicity call, and REVEL is computed from
eighteen scores across thirteen tools including several present in the same
table, agreement between REVEL and SIFT is not two independent observations.

\section{Detection against baselines, and a target-specification failure}
\label{sec:detect}

A separate question is whether the probe \emph{detects} better than standard
alternatives. The attempt produced a methodological error that survived four
sweeps, and is not specific to this method.

We place a $k$-way interaction among $d$ features: the target depends on
$\sin(f\, w^\top x)$ for a random unit vector $w$ over $k=4$ features tilted
away from every axis, plus 2 marginal causes and 14 noise columns, with feature
positions permuted. Raising $f$ raises nonlinearity. Sweeping
$f \in \{1,2,4,8,16\}$ at $d=20$, every method scored $1.000$ at $f \le 2$ and
fell to chance at $f \ge 4$, simultaneously. We read this as the deep probe
having no advantage.

The scoring was \emph{interaction members versus irrelevant}. An
attribution-share breakdown by role shows what the models were doing at $f=8$:
$0.675$ of the mass on the two \emph{marginal} causes---a $6.75\times$
enrichment over their $0.10$ null share---with irrelevant features at $0.272$
against a $0.70$ null. The models had correctly determined that the sine
interaction was unlearnable from 6000 samples (validation loss $0.682$ against
chance $0.693$), abandoned it, and concentrated on the causes that remained
learnable.

\paragraph{The lesson.} Scoring a feature-detection method against a target the
model cannot learn measures the target's learnability, not the method. The
failure is silent: the AUROC is well-formed and lands plausibly above chance.
The guard is cheap---report the fitted model's own generalisation alongside every
detection score. A held-out AUC at chance means the attribution scores describe a
model that learned nothing about that target.

\paragraph{Consequences.} The probe is not worse than the baselines; on the
learnable target it ties them at $1.000$ at every frequency, and an earlier
conclusion that it ``has no niche'' is withdrawn. The cost argument is
unaffected and is now the whole argument: random forest reaches $1.000$ in
$\approx1.4$\,s, the probe in $\approx340$\,s, because the probe retrains once
per feature. The nonlinearity hypothesis is moreover \emph{untestable} with this
system: raising $f$ defeats axis-aligned splits and exceeds the network's sample
complexity at the same point, leaving no window in which one method could win.

\section{Related work}\label{sec:related}

\paragraph{Usable information.} \citet{xu2020theory} define
$\Vinf$-information; \citet{ethayarajh2022understanding} apply it to dataset
difficulty. We use deprivation signatures \emph{inside} the network as the
measurement instrument, in a regime where Shannon information is exactly
degenerate so the dissociation is clean.

\paragraph{Probing.} MDL probes \citep{voita2020information} and control tasks
\citep{hewitt2019designing} measure extractability of properties from
representations of inputs. Our probe measures the representational cost of
\emph{feature removal} in the predictor itself, with explicit null calibration.

\paragraph{Importance under dependence.} \citet{strobl2008conditional} and
\citet{hooker2021unrestricted} document failures of permutation and impurity
importance under correlation; \citet{covert2020understanding} address redundancy
via Shapley averaging. Prop.~\ref{prop:blind} is the limiting exact case for
risk-difference measures specifically. Shapley survives it---on our benchmark
SAGE gives $+0.4513$, $+0.4512$ and $+0.1336$ where every risk difference is
$0.0000$---but cannot orient: cause and non-causal proxy differ by $0.0001$,
which the symmetry axiom requires. That limitation is the explicit motivation
for Asymmetric Shapley Values \citep{frye2020asymmetric}.

\paragraph{Representation geometry and ablation.} Participation ratio as
effective dimensionality, activation-region counting
\citep{hanin2019complexity}, and description length \citep{blier2018description}.
\citet{meyes2020under} ablate \emph{neurons} and relate importance to how much a
unit's incoming weights moved during training---the closest antecedent to our
weight-side channels, though the ablated object there is a neuron and ours is a
feature.

\section{Limitations}\label{sec:limits}

Three synthetic families, all of our own construction, so the dissociation has
not been shown on a system we did not design. The small-capacity regime only,
which Prop.~\ref{prop:capacity} and the width sweep justify but which also
bounds the reach. Ten seeds against a 30-sample null across 57 tests, so
individual $|z|\approx2$ findings sit at the detection floor and are treated as
such.

The functional form of the tracked quantity is not settled
(Appendix~\ref{app:variant}). The probe orders features and does not orient
causes; orientation needs assumptions external to prediction. The comparison
against baselines is bounded by the benchmark rather than settled by it, for the
reason given in Sec.~\ref{sec:detect}. Finally, the literature pass behind
Sec.~\ref{sec:related} was targeted rather than systematic, and has already
demoted one claim we believed novel, so further prior art should be assumed.

\section{Conclusion}

Risk-difference importance has an exact blind spot, and inside it the trained
network still talks---but about economics, not causality. What its internals
reveal is which features the class can cheaply use: an estimate of usable
information that survives when Shannon information is degenerate and inverts the
causal ordering. The practical reading for interpretability is that an
internal-representation importance is a statement about the model's budget.
Re-encode the data and the ordering follows the budget, not the mechanism.

\section{Which $\Vinf$-information variant?}\label{app:variant}

Sec.~\ref{sec:theory} names the \emph{conditional} form, and that is wrong for a
reason the paper already contains: the conditional quantity is what
Prop.~\ref{prop:blind} sends to zero, so under redundancy it is flat by
construction and cannot order anything. Estimating three candidates with the same
network class and rank-correlating against the probe's ordering gives, across
four systems, mean Spearman $\rho$ of $+0.668$ for the marginal form against
$+0.272$ for the conditional. Shapley over the same value function matches the
marginal form wherever the coalition count allowed computing it. We do not claim
the form is settled: \texttt{manifold\_redundancy} reverses the comparison, and
\texttt{parity\_redundancy} is near-uninformative because eight of nine features
have marginal value indistinguishable from zero.

\section{Two measurement traps}\label{app:traps}

\paragraph{$z$-scores across a sweep.} Sweeping width $4$--$128$, the
\emph{$z$-scores} appear to refute Prop.~\ref{prop:capacity}'s predicted decay:
$\sum|z|$ for \texttt{proxy\_cos} rises from $34$ to $148$--$201$. Comparing raw
paired deltas reverses it. Raw effects decay as predicted---participation ratio
by $9.9\times$, val-loss area by $3.7\times$---but the null spread decays faster
($9.0\times$, $8.5\times$), so the ratio flattens. \textbf{A $z$-score is
comparable across sweep points only if the calibration null's variance does not
itself depend on the swept parameter.} Capacity changes signal and noise floor
together.

\paragraph{Post-hoc orientation.} A statistic's sign is not known in advance.
Choosing the orientation that minimises the reported metric is fitting a free
parameter to the answer, and on a handful of draws it reaches zero by chance;
in one of our runs six statistics did so. Orientation must be fixed on a
contrast independent of the metric being scored---we use cause-versus-irrelevant,
which assumes only that ablating a cause disturbs training more than ablating
noise.
